這是什麼 Method

  • 三條獨立指數：Base Set 英文裸卡（raw / ungraded）——1st Edition（第一版）、Shadowless（無限版、無右緣陰影）、Unlimited（後來有陰影的無限版）。不是 Jungle / Fossil 中世代。
  • 固定籃子：Holo Rare + Rare（對照 Base Unlimited 速查 #1–102，有 TCGPlayer ID 才收）。價格加權；成分有人加入／退出時用 divisor 保持連續（S&P 500 同款）。首次保留的每日快照基準＝1,000。
  • 5D／30D／YTD：用 history.json 裡真實快照算區間報酬，缺日就跳過、不補價。每日「今天」仍是 TCGCSV 現況 dump；往回的歷史用免費 TickerMint（tools/backfill_tickermint_vintage.py，按印刷篩 1st／Shadowless／Unlimited，預設 2024-02-08 起每週一點）。不要用 EN 的 backfill_tickermint.py（那支會跳過 1st Edition）。沒有 cutoff 當天或更早的點就 disable，不虛構報酬。
  • 代表價：TCGPlayer Market Price（NM raw），按印刷 subtype 分開：1st Edition 只用 1st Edition 列；Shadowless 用該 group 的 Unlimited 列；Unlimited 用 Base Set group 的 Holofoil／Normal。
  • 卡冊 Binder：同一籃子的格狀速覽（縮圖、編號、USD、有的話才顯示 1D %）。用上方「指數／卡冊」切換；三條指數 tab 共用。搜尋與 Holo／Rare 晶片只篩這一頁，不改指數。
  • 不含：密封盒、Jumbo、JP promo、error 異圖（Black Dot Charizard、Red Cheeks Pikachu）。Machamp 008/102 在 TCGCSV 兩個 Base group 都沒有單卡 ID，暫缺（卡冊裡以虛線口袋標「缺口」）。

資料來源：TCGPlayer Market Price。每日現況經免費 TCGCSV Pokemon dump（category 3）；多日歷史經免費 TickerMint（卡頁例如 tickermint.cards/card/106999）。僅 英文 Base Set 裸卡。對照名單見姊妹站 Base Unlimited cheatsheet。不是投資建議。
