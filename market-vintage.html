這是什麼 Method

  • PC 月線（這頁「PC 月線」／#pc/1st）：四條獨立籃子——Base 1st Edition、Shadowless、Unlimited、Base Set 2。價格只來自 PriceCharting 遊戲頁 VGPC.chart_data 的 used（裸卡／ungraded），美分換美元。每月一點，約在每月 1 日。2023-01-01＝1,000（該月夠厚才當錨；更早的厚月份留在同一條鏈）。Holo Rare＋Rare，與下面 TCG 追逐名單同一刀（#1–22、#70–79）。Machamp 只在有 slug 的印刷版（1st、Shadowless）。Base Set 2 沒有 Machamp、Clefairy Doll、Devolution Spray 的 PC 產品，不補。不是 SNKRDUNK。
  • 三條獨立指數：Base Set 英文裸卡（raw / ungraded）——1st Edition（第一版）、Shadowless（無限版、無右緣陰影）、Unlimited（後來有陰影的無限版）。不是 Jungle / Fossil，也不是 DP→SM（那條在 中世代指數）。TCGPlayer 日脈與此頁 PC 月線是兩條鏈，水平不能直接相減。
  • 固定籃子：Holo Rare + Rare（對照 Base Unlimited 速查 #1–102）。價格加權；有卡加入／退出時用 divisor 保持連續。每條指數基準＝1,000（該條第一個有資料的日子）。
  • 5D／30D／1Y／YTD／All／自訂：用真實歷史點放大圖表，缺日就跳過、不補價、不發明點。All＝該條所有已有日期（全部歷史），只放大、不會重設 1,000。指數水平維持該條第一個有資料日子的固定基準 1,000，不會在視窗開頭重設。沒有夠早的點就不顯示該期間。每日現況來自 TCGCSV；往回的歷史來自 TickerMint。
  • 三條 Overlay：同一張圖重疊第一版／無陰影／無限。期間按鈕（含 All）只放大視窗，不重設 1,000。下方廣度／漲跌榜／籃子仍是你選中的那一條。
  • 落後籃子 Lag vs index：預設 Unlimited。卡片報酬＝該段第一／最後一個真實價；指數報酬＝同一籃子同一期間。差距＝卡 % − 指數 %，負數＝落後，最落後排前面。缺市價跳過。連結同漲跌榜（TCGPlayer／TickerMint）。
  • 漲跌榜：1D／5D／30D／1Y／YTD／自訂。自訂用區間內第一與最後一個真實價圖，不重設指數基準。
  • 廣度 Breadth：跟隨漲跌榜同一個期間按鈕（1D／5D／30D／1Y／YTD／自訂）——一按就即時數該段有確認漲跌的成分（上漲／持平／下跌），不是永遠只看 1 日。
  • 印刷規則：TCGPlayer Market Price（NM raw），三條分開算：1st Edition 只用 1st Edition 列；Shadowless 用無陰影無限版列；Unlimited 用後來有陰影的 Holofoil／Normal。
  • 卡冊 Binder：同一籃子的格狀速覽（縮圖、編號、USD、有的話才顯示 1D %）。上方「指數／卡冊」切換；三條 tab 共用。搜尋與 Holo／Rare 晶片只篩這一頁，不改指數。
  • 不含：密封盒、Jumbo、日版 promo、error 異圖（Black Dot Charizard、Red Cheeks Pikachu）。Machamp 008/102 暫缺可靠單卡市價（卡冊標「缺口」）。

資料來源：TCGPlayer Market Price。每日現況經免費 TCGCSV Pokemon dump（category 3）；多日歷史經免費 TickerMint（卡頁例如 tickermint.cards/card/106999）。僅 英文 Base Set 裸卡。對照名單見姊妹站 Base Unlimited cheatsheet（本站另提供精簡價 cheatsheet.json，Holo／Rare 有市價才有數字，不虛構）。不是投資建議。
