  • 預設敘事是 PSA。CGC 與 Beckett (BGS) 需手動開啟，且各有獨立欄與獨立百分比，不會在未標示的情況下加總成一個「全市場％」。
  • 累積百分比回答「此級或以上佔多少」：自 10 向 1 累加。開啟半級時，9.5 列＝（10＋9.5）÷總量。
  • 半級預設併入較低整數級，與 PriceCharting 公開說明一致（8.5 計入 8）。勾選後方分列；目前公開頁多半已先合併，無法還原的半級列為「—」。
  • 下拉標籤顯示卡名、參考印刷版（優先 Unlimited）的 PSA10 人口，以及該版 PSA10 ÷ PSA 總量。
  • 編號對照：Base Set 2 重編部分卡號（例如 Venusaur Base #15 → Base Set 2 #18；Gyarados #6 → #7）。Machamp #8 無 Base Set 2 對應，不列入。Base Set Clefable #5 因 PriceCharting 無正確命名的 Base Set 人口頁，亦不列入。
  • 來源厚薄不一：部分 Unlimited 頁在 PriceCharting 上人口極少（例如部分御三家閃卡的無標版條目），本站照實顯示、不補數。請以各欄連到的 POP 頁為準。
  • 來源：公開 PriceCharting POP 頁（PSA、CGC；對方約每月更新）。本站以 GitHub Actions 每週抓取並寫入靜態 JSON。解析失敗會讓週更作業失敗，不會填入臆造人口。
