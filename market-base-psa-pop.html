Base Set POP 比較

比較同一張英文 Base Set 卡在 1st Edition、Unlimited、Base Set 2 的評級 POP。各欄 pop 為該印刷版的 PSA＋CGC 合計（來源無 CGC 則僅計 PSA）。百分比分母為同一合計。

這是什麼 · 方法

  • pop 為 PSA＋CGC 合計。同一印刷版、同一級別的 PSA 與 CGC 相加；來源無 CGC 欄則僅計 PSA。百分比分母為該合計，各印刷版分開計算。
  • 累積百分比回答「此級或以上佔多少」：自 10 向 1 累加。開啟半級時，9.5 列＝（10＋9.5）÷總量。
  • 半級預設併入較低整數級，與 PriceCharting 公開說明一致（8.5 計入 8）。勾選後方分列；目前公開頁多半已先合併，無法還原的半級列為「—」。
  • 下拉列出英文 Base Set #1–102（有 PriceCharting POP 頁者）。標籤顯示參考印刷版（優先 Unlimited）的 PSA＋CGC 10 人口，以及該數 ÷ 合計總量。可用搜尋框篩選。
  • 手機表同一張表並列 1st Edition 與 Unlimited。桌面另列 Base Set 2（無對應則為「—」）。
  • 編號對照：Base Set 2 重編部分卡號（例如 Venusaur Base #15 → Base Set 2 #18）。Machamp #8 僅有 1st Edition 頁，Unlimited／Base Set 2 為「—」。變體（error、Red Cheeks 等）不列入。
  • 來源厚薄不一：部分 Unlimited 頁在 PriceCharting 上 POP 極少，本站照實顯示、不補數。請以各欄連到的 POP 頁為準。
  • 來源：公開 PriceCharting POP 頁（PSA、CGC；對方約每月更新）。本站以 GitHub Actions 每週抓取並寫入靜態 JSON。解析失敗會讓週更作業失敗，不會填入臆造 POP。
