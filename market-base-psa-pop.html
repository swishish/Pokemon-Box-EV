這是什麼 · 方法

  • 預設 pop 為 PSA＋CGC 合計。同一印刷版、同一級別的 PSA 與 CGC 相加；來源無 CGC 欄則僅計 PSA。百分比分母為該合計，各印刷版分開計算。
  • 分開 PSA 與 CGC：開啟後同一張表分列兩家公司的 pop／%（百分比分母改為該公司總量）。不含 Beckett。
  • 累積百分比回答「此級或以上佔多少」：自 10 向 1 累加。
  • 半級固定併入較低整數級，與 PriceCharting 公開說明一致（8.5 計入 8）。本頁不再提供半級分列。
  • 下拉列出英文 Base Set #1–102，標籤以編號開頭（例如 #1 Alakazam）。可用搜尋框篩選。選卡後才載入該張圖。
  • 手機表同一張表並列 1st Edition、Shadowless 與 Unlimited。桌面另列 Base Set 2（無對應則為「—」）。
  • 編號對照：Base Set 2 重編部分卡號（例如 Venusaur Base #15 → Base Set 2 #18）。Machamp #8 無 Unlimited／Base Set 2 頁（1st／Shadowless 有則照列）。變體（error、Red Cheeks 等）不列入。
  • 來源厚薄不一：部分 Unlimited 頁在 PriceCharting 上 POP 極少，本站照實顯示、不補數。請以各欄連到的 POP 頁為準。
  • PriceCharting 指示價：同一印刷版的公開 game 頁欄位，不是 POP 表、也不是即時成交。對照：Ungraded（used）＝raw；Grade 7（complete）；Grade 8（new）；Grade 9（graded）；PSA 10（manual_only）。缺欄顯示「—」，不臆造。畫面以港元顯示（USD × 7.80，與開盒 EV／Chase 同一固定匯率）。
  • 來源：公開 PriceCharting POP 頁（PSA、CGC；對方約每月更新）與同一 slug 的 game 頁指示價。本站以 GitHub Actions 每週抓取並寫入靜態 JSON。解析失敗會讓週更作業失敗，不會填入臆造 POP；指示價缺漏則保留上次或留空。
